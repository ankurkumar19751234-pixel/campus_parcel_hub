OUR PROJECT

About Us

A simple website concept for managing parcel deliveries on campus.

Why we made it

Parcels pass through several steps before a student collects them. This project gives the desk one place to record a parcel and update its progress, so the current status is easy to check.

What the website does

  • Records a student's name, student ID, and hostel or block.
  • Shows the parcel's current status.
  • Lets desk staff move a parcel to its next status.
  • Lets a student find parcels using their student ID.

How we built it

HTML
Creates the pages, forms, links, and parcel table.
CSS
Controls the colors, spacing, and layout on different screen sizes.
JavaScript
Adds parcels, updates statuses, and searches by student ID.
Browser storage
Keeps the demo parcel list in this browser after a refresh.

This is a student project demo. It has no server or secure student sign-in, so use sample details only.
